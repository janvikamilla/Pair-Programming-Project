🤖 ROBOT APOCALYPSE

Ultimate Robot Survival Simulator

Welcome to Robot Apocalypse — a Python-based survival simulation project set in a world destroyed by robots, aliens and zombies.

Your mission is to survive, fight enemies, rescue survivors and protect humanity.

🎮 Project Features

- Main Survival Mission
- Disaster Alert System
- Robot Army Management
- Alien Invasion
- Black Market
- Hacking Terminal
- Final Apocalypse Challenge
- Player Achievements
- Robot Battle Arena
- Robot Inventory System
- Robot Customization Garage
- Random Mission Generator
- Zombie Outbreak Survival
- Secret Underground Bunker
- AI Enemy Intelligence

🛠️ Technologies Used

- Python 3
- Random Module
- Time Module
- JSON
- OS Module
- Subprocess Module

📂 Project Structure

Each Python file represents a separate game mode or simulation system.

"game_launcher.py" provides the main menu to launch the individual modules.

🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

"python game_launcher.py"

🎯 Project Objective

To explore Python programming through interactive simulations involving robotics, artificial intelligence, survival mechanics and decision-making systems.
